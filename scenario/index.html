資料來源與模型假設

  • 各市場預設值是依公開報導整理的示意價格型態，不是即時市場數據；正式使用前請以歷史電價校準。
  • 歷史電價：手動上傳。AEMO 網站的月檔不開放跨網域讀取，網頁無法直接下載。
  • 特殊日期備註：開頁時與按「重新整理備註」時向 GitHub API 讀取未關閉、標籤為 special-date 的 issue。未登入時每個網路每小時最多 60 次，所以不會自動輪詢。
  • 每日電價由基準價、午間再生能源凹陷、傍晚尖峰、天氣波動與偶發尖峰組成，模擬 400 條路徑（固定亂數種子，同樣輸入得到同樣結果）。
  • 每天若電池為空，於當日最低價的連續四小時充電；之後出現的最高價連續四小時，若與充電價的價差達標即放電，否則持有，最多等待設定天數後強制放電。
  • 收益＝放電電量 ×（高價段均價 − 低價段均價）；來回效率固定 100%，不計電池損耗、輔助服務、容量收入、網路費與損失係數。
  • 此工具假設發電與用電業者的參與量沒有劇烈變化；若市場結構改變（大量新電池、電廠退場、規則修訂），預設值需重新校準。
  • 天氣與相關市場的換算係數（例如每偏離 1°C 需求增加的比例、風電與鄰近市場電價的傳導比例）為初始假設，會依備註與實際結果調整。
