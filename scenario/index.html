價差標準檢討：歷史收益保留率

以 data/daily_summary.json 每天既有的最佳計畫（事後電價，計入效率與損耗）逐日套用不同門檻：當天每個循環的價差都達到門檻才執行，否則當天不做。結果是「目前標準保留多少歷史可得收益、錯過哪些日子」，不是最佳營運門檻，也沒有計入預測誤差。

    資料來源與模型假設

    • 各市場預設值是依公開報導整理的示意價格型態，不是即時市場數據；正式使用前請以歷史電價校準。
    • 歷史電價：手動上傳。AEMO 網站的月檔不開放跨網域讀取，網頁無法直接下載。
    • 特殊事件：開頁時讀取 repo 內的 data/special_dates.csv，內容經 PR 審核後才會更新，不呼叫 GitHub API。
    • 每日收益：開頁時讀取 repo 內的 data/daily_summary.json，由離線分析層每月更新；資料不完整的日子不畫長條。
    • 價差標準檢討：目前標準讀自 config/spread_standard.json，候選標準從 0 到「期間內最高每日價差向上取整」與目前標準的較大值，每 1 AUD/MWh 一個；可輸入試算標準、來回效率與損耗暫時改看其他情境；試算效率與損耗沿用每日摘要原本的充放電時段重算淨收益（不重新選窗，為下限估計）。頁面不會修改任何設定檔。
    • 每日電價由基準價、午間再生能源凹陷、傍晚尖峰、天氣波動與偶發尖峰組成，模擬 400 條路徑（固定亂數種子，同樣輸入得到同樣結果）。
    • 每天若電池為空，於當日最低價的連續四小時充電；之後出現的最高價連續四小時，若與充電價的價差達標即放電，否則持有，最多等待設定天數後強制放電。
    • 收益＝放電電量 ×（高價段均價 − 低價段均價）；來回效率固定 100%，不計電池損耗、輔助服務、容量收入、網路費與損失係數。
    • 此工具假設發電與用電業者的參與量沒有劇烈變化；若市場結構改變（大量新電池、電廠退場、規則修訂），預設值需重新校準。
    • 天氣與相關市場的換算係數（例如每偏離 1°C 需求增加的比例、風電與鄰近市場電價的傳導比例）為初始假設，會依事件清單與實際結果調整。
